告警开关

资源占用提醒 每分钟检测一次 CPU、内存、网络，持续超阈值时发信
全新 IP 登录提醒 每次 SSH 登录都核对，只有从未出现过的 IP 才发信
登录失败密集提醒 记录每一次失败尝试；同一 IP 在窗口内失败达到次数就发信

关闭开关立即生效：检测和记录仍在继续（数据继续显示），只是不再发信。资源开关关闭时用量仍会每分钟采样。

判定规则

登录失败判定

自动封锁

失败次数达到阈值时自动封锁该 IP 关闭时只能手动点「封锁」。开启后由服务自动执行，记录中标为「自动」。

自动封锁同样受安全规则约束：成功登录过、有已登录会话、受保护 IP、内网地址一律不封。

SSH 国家/地区过滤

开启允许连接SSH的国家/地区白名单 开启后，只有勾选的国家/地区能连接 SSH（22 端口），其余直接拒绝；网站、邮件等其他端口不受影响

允许的国家/地区（勾选后点「保存国家列表」立即生效）

受保护 IP、成功登录过的 IP 和本机地址始终放行；已拉黑的 IP 仍然优先拦截。数据来自 ipdeny.com，每天自动更新。

网络流量过滤

开启流量过滤 在防火墙层按下面的规则拦截或放行指定来源的流量。规则按优先级从上往下匹配，第一条命中的规则决定结果。

失败页内容（https://blocked.example.com/ 的 HTML，可编辑）

「失败页」模式下，被拦截的访客会被 302 跳转到这个独立域名。下面就是该页面的完整 HTML，保存后立即生效；默认版本按访客浏览器的语言显示提示，没有匹配语言时使用英语。

端口规则同时拦截 TCP 与 UDP，避免 QUIC / HTTP3 绕过；选「所有端口」时对 ICMP 等全部协议生效，请谨慎使用。自定义端口的「其他」支持端口列表、范围，或对十进制端口号整体匹配的正则（如 8\d{3}）。受保护 IP、成功登录过的 IP、本机地址和你当前访问的地址会在所有规则之前自动放行，所以「拦截中国大陆」这类规则不会把你关在门外。公共站点在 Cloudflare 后面时，nginx 会从 Cloudflare 网段信任 CF-Connecting-IP 还原访客真实 IP，因此按国家/IP 的规则对经过 Cloudflare 的浏览器访问同样生效；静默失败和失败页模式还会用 Cloudflare 的 CF-IPCountry 补充国家判断，显式放行和自动豁免仍然优先。

失败的登录尝试

同一 IP 在窗口内的失败次数，达到阈值就会发信。

暂无记录

「失败次数」只统计当前窗口内的尝试，窗口滑过会减少；「首次」「最近」来自永久记录，一旦出现就会保留，直到手动清空。

只清除「首次 / 最近 / 累计次数」的永久记录，不会解锁任何 IP，也不影响当前窗口的统计。

已拉黑的 IP

被封锁的 IP 在 SSH 端口上的连接会被内核直接丢弃，尝试仍会持续记录在这里。

暂无记录

已记录的登录 IP

成功登录过的 IP 都会记录；只有首次出现的公网 IP 会发信，之后同一 IP 再登录不会重复提醒。
